# ШПИГУН · онлайн

Гра «Шпигун» для компанії просто в браузері. **Реєстрація не потрібна** — ані в Claude, ані деінде: відкрив посилання, створив кімнату, кинув друзям код із чотирьох літер.

## 🎮 Грати

**https://stasikyovbak.github.io/shpyhun/**

Кожен відкриває це саме посилання зі свого телефона. Можна ділитися й прямим посиланням на кімнату — `.../shpyhun/#КОД`, тоді код підставиться сам.

## Правила

- Треба щонайменше **троє** гравців.
- Усім випадає одна спільна локація, одному — картка **ШПИГУН**: він локації не знає.
- Гравці по колу ставлять одне одному запитання (уголос), передаючи хід тапом по імені. На хід — 60 секунд.
- Мирні шукають того, хто «плаває», шпигун — намагається зрозуміти, де всі опинилися.
- Будь-хто може оголосити голосування. Якщо більшість вказала на шпигуна — у нього є останнє слово: назве локацію правильно, забере раунд собі.
- Рахунок «мирні : шпигуни» тримається між раундами.

## Як це працює

Один файл `index.html` — жодного сервера й бази. Браузери гравців спілкуються між собою через **публічний MQTT-брокер по WebSocket** (emqx / HiveMQ / Mosquitto, з автоматичним перемиканням між ними). Стан кімнати тримає «ведучий» — той, хто її створив; якщо він зникає, ведення автоматично підхоплює хтось інший, і гра триває.

Бібліотека [MQTT.js](https://github.com/mqttjs/MQTT.js) лежить у репозиторії поруч (`mqtt.min.js`), тож гра стартує навіть тоді, коли CDN недоступний.

## Що виправлено проти першої версії

| Було | Стало |
|------|-------|
| Будь-який обрив зв'язку (телефон перемкнувся з Wi-Fi на мобільний, екран заблокувався) **скидав гру в лобі просто посеред раунду** — бо після перепід'єднання наново виконувався код створення кімнати | Кімната створюється рівно один раз; перепід'єднання лише повертає стан у ефір |
| Помилка брокера плодила паралельних MQTT-клієнтів, і застосунок міг лишитися з «мертвим» клієнтом — гра не запускалася взагалі | Кожне під'єднання пронумероване, старі клієнти глушаться; брокери перебираються по черзі з поверненням до робочого |
| Гра не стартувала без CDN | Бібліотека лежить у репозиторії |
| «Почати гру» могла нічого не робити мовчки | Кнопка пояснює причину; ведучий рахує гравців так само, як показує список |
| Гравця, чий телефон заснув на 25 с, викидало **посеред раунду** — зникало ім'я, а голосування зависало назавжди | Склад фіксується на час раунду; запас — 45 с; голосування не чекає на того, хто справді пішов |
| Голосування без кворуму й «останнє слово» шпигуна могли зависнути назавжди | Таймери: 90 с на голосування, 60 с на відповідь шпигуна |
| Кімната лишалася «примарою» в брокері після виходу ведучого | Ведучий прибирає за собою збережений стан |
