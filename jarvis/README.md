# J.A.R.V.I.S. — голосовий асистент «Джарвіс» для Android

Слухає мікрофон постійно, навіть із вимкненим екраном. Скажіть **«Джарвіс»** — пролунає сигнал і почнеться
запис команди. Скажіть **«Виконуй»** — команда виконується, а Джарвіс відповідає голосом.
**«Скасуй»** скидає команду; якщо за 30 секунд «Виконуй» так і не прозвучало, команда скасовується сама.

* Розпізнавання мови **офлайн** через [Vosk](https://alphacephei.com/vosk/) (українська модель): без сигналів Google,
  без витрат інтернету, без обмежень на безперервне слухання. Звук із мікрофона нікуди не надсилається.
* Шаблонні команди працюють без інтернету й без жодних ключів.
* **Розумний режим**: усе, що не підійшло під шаблони, іде в Claude API (офіційний Java SDK), і Claude керує
  телефоном крок за кроком, аж до натискання кнопок в інших програмах через службу спеціальних можливостей.
* Kotlin, Android 10+ (minSdk 29), темна тема в стилі Iron Man, анімований «дуговий реактор» як індикатор стану.

## 1. Що вміє

| Скажіть | Що станеться | Потрібно |
|---|---|---|
| «Джарвіс, увімкни пісню Believer через ютуб. Виконуй» | Знаходить відео через YouTube Data API і **одразу відтворює перше** в застосунку YouTube | ключ YouTube (без нього — відкриє пошук) |
| «Джарвіс, відкрий телеграм. Виконуй» | Нечіткий пошук серед встановлених програм («ютуб», «вайбер», «калькулятор»…) | — |
| «Джарвіс, подзвони мамі. Виконуй» | Знаходить контакт навіть у відмінку («мамі», «Олегу»), **перепитує «так/ні»**, дзвонить | Контакти, Дзвінки |
| «Джарвіс, напиши мамі повідомлення буду о сьомій. Виконуй» | Зачитує текст, **перепитує «так/ні»**, надсилає SMS | Контакти, SMS |
| «Джарвіс, увімкни ліхтарик / вимкни ліхтарик. Виконуй» | Спалах камери | — (дозвіл камери не потрібен) |
| «Джарвіс, гучність на п'ятдесят відсотків. Виконуй» | Гучність мультимедіа; також «гучніше», «тихіше», «на максимум», «вимкни звук» | — |
| «Джарвіс, постав будильник на сьому тридцять. Виконуй» | Будильник у «Годиннику». Розуміє «пів на восьму», «о дев'ятій вечора», «через двадцять хвилин» | — |
| «Джарвіс, постав таймер на десять хвилин. Виконуй» | Таймер. Розуміє «півгодини», «півтори години», «хвилину тридцять секунд» | — |
| «Джарвіс, прокладай маршрут до залізничного вокзалу. Виконуй» | Навігація Google Maps | — |
| «Джарвіс, котра година. Виконуй» / «який заряд батареї» / «яке сьогодні число» | Відповідає голосом | — |
| «Джарвіс, знайди в гуглі рецепт борщу. Виконуй» | Пошук Google | — |
| «Джарвіс, увімкни вайфай. Виконуй» | Відкриває панель Wi-Fi (Android 10+ не дає програмам вмикати Wi-Fi самим) | — |
| Будь-що інше: «скільки буде 17 на 23», «відкрий телеграм і напиши Олегу привіт», «прокрути вниз», «натисни "Надіслати"» | Розумний режим (Claude) | ключ Claude; для дій усередині програм — Спеціальні можливості |

**Підтвердження «Так / Ні»** голосом обов'язкове перед дзвінком, SMS і будь-якою дією розумного режиму, яку не можна
скасувати (надіслати, видалити, оплатити, купити, підтвердити…). Мовчання 15 секунд = «ні».

**Головний екран:** великий перемикач «Джарвіс увімкнено/вимкнено», реактор-індикатор (Слухаю / Записую команду /
Виконую / Чекаю «так чи ні» / Помилка), поле «Чую» (живий текст з мікрофона), остання команда, журнал останніх 20 команд.

**Налаштування:** слово активації (типово «Джарвіс») і варіанти того, як модель його чує, слово виконання
(«Виконуй»), слово скасування («Скасуй»), тайм-аут, ключі Claude і YouTube (зберігаються в EncryptedSharedPreferences),
кнопки «Отримати ключ» і «Вставити» біля кожного ключа, модель Claude і глибина міркувань, голос і швидкість TTS, сигнал/вібрація, вибір моделі Vosk і другої мови.

## 2. Найшвидший старт: готовий APK

У цій теці лежить уже зібраний файл **`jarvis-1.0.apk`** (≈26 МБ). Якщо не хочете нічого збирати:

1. Скопіюйте `jarvis-1.0.apk` на телефон (кабелем, Telegram «Збережене», Google Диск — як зручно).
2. Відкрийте його у «Файлах». Android попросить дозволити встановлення з цього джерела:
   **Налаштування → Дозволити з цього джерела** → назад → **Встановити**.
3. Переходьте до розділу [7](#7-перший-запуск-і-налаштування-телефона).

> APK підписано тестовим (debug) ключем. Якщо пізніше зберете власний у Android Studio, спершу видаліть
> цю версію з телефона — інакше Android скаже, що підписи не збігаються.

## 3. Збирання в Android Studio — кнопка за кнопкою

### Крок 1. Встановіть Android Studio
1. Відкрийте <https://developer.android.com/studio> → **Download Android Studio** → погодьтеся з умовами → завантажте.
2. Встановіть і запустіть. У майстрі першого запуску (**Setup Wizard**) оберіть **Standard** → **Next** → **Finish**.
   Майстер сам завантажить Android SDK (кілька ГБ, потрібен інтернет).

### Крок 2. Отримайте проєкт

**Варіант А (рекомендовано, без копіювання файлів).**
1. На сторінці репозиторію на GitHub натисніть зелену кнопку **Code → Download ZIP** і розпакуйте архів.
2. В Android Studio: **File → Open…** (на стартовому екрані — **Open**) → оберіть теку **`jarvis`**
   (саме її, ту, де лежить `settings.gradle.kts`) → **OK** → **Trust Project**.
3. Внизу праворуч з'явиться прогрес **Gradle Sync**. Перший раз він триває 3–10 хвилин: завантажуються
   Gradle 9.7.1, Android Gradle Plugin 9.3.3 і бібліотеки. Дочекайтеся напису *BUILD SUCCESSFUL* / зникнення прогресу.
4. Якщо Android Studio запропонує оновити Android Gradle Plugin («AGP Upgrade Assistant») — можна відмовитися
   (**Remind me tomorrow** / **Don't ask for this project**): проєкт перевірено саме з цими версіями.

**Варіант Б (створити проєкт самому й вставити файли).** Довше й легше помилитися, але так ви побачите кожен файл:
1. **File → New → New Project… → Empty Views Activity → Next**.
2. Заповніть: **Name** `Jarvis`, **Package name** `ua.jarvis.assistant`, **Language** `Kotlin`,
   **Minimum SDK** `API 29 ("Q"; Android 10.0)`, **Build configuration language** `Kotlin DSL` → **Finish**.
3. Угорі ліворуч перемкніть вигляд дерева з **Android** на **Project** — так видно справжні теки.
4. Замініть уміст файлів `settings.gradle.kts`, `build.gradle.kts` (кореневий), `gradle.properties`,
   `app/build.gradle.kts`, `app/proguard-rules.pro`, `app/src/main/AndroidManifest.xml`,
   `gradle/wrapper/gradle-wrapper.properties` на файли з цього репозиторію.
   Файл `gradle/libs.versions.toml` можна лишити або видалити — наші файли його не використовують.
5. Видаліть створений шаблоном `app/src/main/java/ua/jarvis/assistant/MainActivity.kt` і `res/values/themes.xml`
   (теку `res/values-night`, якщо є, теж).
6. Для кожного пакета (`actions`, `commands`, `core`, `service`, `smart`, `speech`, `text`, `ui`):
   правою кнопкою на `app/src/main/java/ua.jarvis.assistant` → **New → Package** → назва.
   Далі правою кнопкою на пакеті → **New → Kotlin Class/File** → оберіть **File** → назва без `.kt` → вставте вміст.
   Повний список файлів — у розділі [13](#13-структура-проєкту).
7. Ресурси: правою кнопкою на `res/layout` → **New → Layout Resource File** (або просто **New → File**) і вставте
   XML; так само `res/drawable`, `res/values`, `res/xml` (теку `xml` створіть через **New → Android Resource Directory →
   Resource type: xml**), `res/mipmap-anydpi-v26` (замініть шаблонні `ic_launcher.xml` і `ic_launcher_round.xml`).
8. Unit-тести (необов'язково) — у `app/src/test/java/ua/jarvis/assistant/...`.
9. Натисніть **File → Sync Project with Gradle Files** (іконка слона зі стрілкою).

### Крок 3. Зберіть APK
1. Угорі в меню: **Build → Generate Bundle(s) / APK(s) → Generate APK(s)**.
   (У старіших версіях Android Studio пункт називається **Build → Build Bundle(s) / APK(s) → Build APK(s)**.)
2. Коли збірка завершиться, праворуч унизу з'явиться сповіщення з посиланням на файл — натисніть його.
   Файл лежить тут: `jarvis/app/build/outputs/apk/debug/app-debug.apk`.
3. Альтернатива з терміналу (вкладка **Terminal** унизу Android Studio):
   `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`). Перевірити логіку без телефона:
   `./gradlew testDebugUnitTest`.

### Крок 4. Встановіть на телефон
**Кабелем (зручно для частих змін):**
1. На телефоні: **Налаштування → Про телефон → 7 разів натисніть «Номер збірки»**
   (на Xiaomi — «Версія MIUI»/«Версія ОС»). З'явиться «Ви стали розробником».
2. **Налаштування → Система → Для розробників → Налагодження через USB** — увімкнути.
   На Xiaomi додатково: **«Встановлення через USB»** і **«Налагодження USB (налаштування безпеки)»**.
3. Підключіть телефон кабелем, на телефоні дозвольте налагодження для цього комп'ютера.
4. В Android Studio на панелі вгорі оберіть свій телефон у списку пристроїв і натисніть зелений **▶ Run 'app'**.

**Файлом:** скопіюйте `app-debug.apk` на телефон і встановіть, як у [розділі 2](#2-найшвидший-старт-готовий-apk).

## 4. Модель Vosk: куди покласти і як підвантажується

**Нічого робити не потрібно.** Коли ви вперше вмикаєте Джарвіса, він сам завантажує модель
`vosk-model-small-uk-v3-small` (138 МБ, краще через Wi-Fi) з <https://alphacephei.com/vosk/models>
і розпаковує її у внутрішню пам'ять програми: `/data/data/ua.jarvis.assistant/files/vosk/` (~420 МБ).
Прогрес видно на головному екрані й у сповіщенні. Наступні запуски — миттєві й без інтернету.

**Без інтернету на телефоні (модель усередині APK):**
1. На комп'ютері завантажте `vosk-model-small-uk-v3-small.zip` зі сторінки <https://alphacephei.com/vosk/models>
   і розпакуйте.
2. В Android Studio: правою кнопкою на `app/src/main` → **New → Folder → Assets Folder → Finish**.
3. Перетягніть розпаковану теку так, щоб вийшло:
   `app/src/main/assets/vosk-model-small-uk-v3-small/am/final.mdl` (а також `conf/`, `graph/`, `ivector/`).
4. Зберіть APK. При першому запуску модель скопіюється з APK, а не завантажиться.
   APK стане більшим на ~140 МБ (стиснутий).

**Яку модель обрати** (Налаштування → Розпізнавання):

| Модель | Архів | На диску | Слово «джарвіс» у словнику |
|---|---|---|---|
| `vosk-model-small-uk-v3-small` (за замовчуванням) | 138 МБ | ~420 МБ | ✅ є (як і «виконуй», «скасуй», «ютуб») |
| `vosk-model-small-uk-v3-nano` | 73 МБ | ~130 МБ | ❌ немає — оберіть інше слово активації, напр. «комп'ютер» |

Після запуску Джарвіс сам перевіряє словник моделі й попереджає, якщо вашого слова активації там немає.

**Друга мова для назв пісень** (англійська або російська, +40–45 МБ): друга модель слухає лише під час запису
команди, а Claude отримує обидва варіанти почутого й обирає правильну назву.

## 5. Ключ Claude API

> **Найпростіше — прямо з телефона.** У Джарвісі: ⚙ **Налаштування → Розумний режим (Claude) → «Отримати ключ»**.
> Відкриється підказка з кнопками **«1. Поповнити рахунок»** і **«2. Створити ключ»**, що ведуть на потрібні сторінки.
> Скопіюйте ключ, поверніться в Джарвіс і натисніть **«Вставити»**: ключ сам знайдеться в скопійованому тексті,
> збережеться, системний буфер обміну очиститься, і одразу пройде перевірка. Якщо ваша клавіатура зберігає
> історію буфера обміну (наприклад, Gboard), видаліть ключ і звідти — це програма зробити не може.
> Нижче — ті самі кроки докладно.

1. Відкрийте <https://platform.claude.com> (адреса `console.anthropic.com` веде туди ж) → **Sign up** / **Log in**.
2. Поповніть рахунок: **Settings → Billing** → додайте картку й купіть кредити (від $5). Без кредитів ключ
   повертатиме помилку, і Джарвіс скаже «На рахунку Claude API закінчилися кошти».
3. **Settings → API keys** (<https://platform.claude.com/settings/keys>) → **Create key** → назва `Jarvis` → **Create**.
4. Ключ (`sk-ant-…`) показується **лише один раз** — скопіюйте його.
5. У Джарвісі: ⚙ **Налаштування → Розумний режим (Claude)** → **«Вставити»** (або вставте вручну в поле
   «Ключ Claude API» і натисніть **«Перевірити ключ Claude»**).

**Модель** задається в тому ж розділі. За замовчуванням `claude-opus-5-5` — найрозумніша. Для швидших і
дешевших відповідей впишіть `claude-haiku-5-5` (або `claude-sonnet-5-5` як середину). **Глибина міркувань (effort)**
за замовчуванням `low` — для голосового асистента це найкращий баланс швидкості.
Для моделей Opus 5.5 / Sonnet 5.5 / Fable 5.1 застосунок вмикає server-side fallback: якщо запобіжники
безпеки відхилять запит, API сам повторить його на іншій моделі.

## 6. Ключ YouTube Data API v3

> **З телефона:** ⚙ **Налаштування → YouTube → «Отримати ключ»** — у підказці є кнопки **«1. Увімкнути API»** і
> **«2. Створити ключ»**. Скопіюйте ключ і натисніть **«Вставити»** — перевірка запуститься сама.

Без ключа Джарвіс відкриває **сторінку пошуку** YouTube. З ключем — знаходить відео й **одразу вмикає перше**.

1. Відкрийте <https://console.cloud.google.com> і увійдіть Google-акаунтом.
2. Угорі зліва від пошуку натисніть список проєктів → **New Project** → назва `Jarvis` → **Create** → оберіть цей проєкт.
3. **☰ меню → APIs & Services → Library** → у пошуку введіть `YouTube Data API v3` → відкрийте → **Enable**.
4. **☰ меню → APIs & Services → Credentials** → **+ Create credentials → API key**. Скопіюйте ключ (`AIza…`).
5. (Рекомендовано) Натисніть на створений ключ → **API restrictions → Restrict key** → позначте
   **YouTube Data API v3** → **Save**. Обмеження «Android apps» **не ставте** — запити йдуть без підпису застосунку,
   і ключ перестане працювати.
6. У Джарвісі: ⚙ **Налаштування → YouTube** → **«Вставити»** (або вручну в поле й **«Перевірити ключ YouTube»**).

Квота безкоштовна: 10 000 одиниць на добу, один пошук = 100 одиниць, тобто ~100 пісень на день.

## 7. Перший запуск і налаштування телефона

1. Відкрийте **Джарвіс**. З'явиться екран **«Підготовка систем»**: біля кожного дозволу написано, навіщо він.
   Натискайте **Надати** по черзі:
   * **🎙 Мікрофон** — обов'язково.
   * **🔔 Сповіщення** — обов'язково (Android вимагає видиме сповіщення, поки мікрофон працює у фоні).
   * **👥 Контакти**, **📞 Дзвінки**, **✉️ SMS** — для відповідних команд.
   * **♿ Спеціальні можливості** — у списку знайдіть **Джарвіс** → увімкніть → **Дозволити**.
     Якщо перемикач сірий і пише «Обмежене налаштування» (Android 13+ для програм не з Google Play):
     **Налаштування → Програми → Джарвіс → ⋮ (угорі праворуч) → Дозволити обмежені налаштування**, потім знову.
   * **🔋 Робота без обмежень батареї** — **Дозволити**.
   * **🪟 Поверх інших вікон** — необов'язково, запасний спосіб відкривати програми з фону.
   * 💡 Окремий дозвіл камери для ліхтарика **не потрібен**.
2. Натисніть **Готово** → на головному екрані увімкніть великий перемикач. Перший раз завантажиться модель.
3. Коли статус стане **СЛУХАЮ**, скажіть: «Джарвіс» (сигнал) → «котра година» → «Виконуй».

### Щоб телефон не «вбивав» Джарвіса у фоні
Кнопка в застосунку: **Налаштування → Робота у фоні → Автозапуск і «вбивання» у фоні** — відкриває інструкцію
саме для вашого виробника та потрібну сторінку налаштувань.

**Xiaomi / Redmi / POCO (MIUI, HyperOS):**
1. **Налаштування → Програми → Керування програмами → Джарвіс → Автозапуск** — увімкнути.
2. Там же **Економія заряду (Battery saver) → Без обмежень (No restrictions)**.
3. **Інші дозволи** → дозволити **«Відображати спливні вікна, коли працює у фоні»** і **«Показувати на заблокованому екрані»**.
4. Відкрийте список нещодавніх програм, потягніть картку Джарвіса вниз і натисніть **замок 🔒**.

**Samsung (One UI):**
1. **Налаштування → Програми → Джарвіс → Акумулятор → Без обмежень**.
2. **Налаштування → Догляд за батареєю (Обслуговування пристрою) → Акумулятор → Обмеження фонового використання** →
   додайте Джарвіса в **«Програми, які ніколи не переходять у режим сну»**; вимкніть
   **«Переводити невикористовувані програми в режим сну»**.
3. Якщо засинає — вимкніть **«Адаптивне енергоспоживання»**.

Для інших марок — <https://dontkillmyapp.com>.

## 8. Як говорити з Джарвісом

* Скажіть «Джарвіс» → коротка пауза → сигнал/вібрація → команда → «Виконуй». Можна й одним духом:
  «Джарвіс увімкни ліхтарик виконуй».
* Дивіться на поле **«Чую»**: там видно, як саме модель почула вас. Якщо «Джарвіс» виходить як «джервіс» чи
  «дарвіс» — допишіть це в **Налаштування → Як модель іноді чує це слово**.
* «Виконуй» розпізнається точно або зі схожим закінченням («виконую») — але схоже слово рахується лише в кінці фрази,
  щоб «я виконую обіцянку» не запускало команду.
* «Скасуй» спрацьовує лише в кінці фрази — тому «Джарвіс, скасуй будильник, виконуй» — це звичайна команда.
* Під час виконання розумного режиму можна сказати «Скасуй», щоб зупинити його.
* Перед дзвінком/SMS відповідайте «так» або «ні» після запитання.

## 9. Чесно: що на Android неможливо і чим це замінено

| Бажання | Обмеження Android / сервісів | Що зроблено замість |
|---|---|---|
| Автозапуск після перезавантаження | На Android 11+ фоновій програмі **заборонено вмикати мікрофон** без дії користувача; на Android 14+ запуск мікрофонного сервісу з `BOOT_COMPLETED` блокується повністю | Android 10: стартує сам. Android 11+: після перезавантаження з'являється сповіщення **«Торкніться, щоб Джарвіс почав слухати»** — один дотик |
| Відкривати програми, коли екран вимкнено чи відкрита інша програма | З Android 10 фонові програми не можуть відкривати екрани | Запуск через службу спеціальних можливостей (виняток Android) або дозвіл «Поверх інших вікон»; інакше — сповіщення «Торкніться, щоб відкрити» |
| Виконувати команди на заблокованому телефоні | Програми не можуть обійти блокування екрана | Ліхтарик, гучність, час, батарея, SMS і дзвінки працюють одразу. Для програм (YouTube, карти, будильник) екран вмикається, Джарвіс просить розблокувати й виконує команду протягом 90 с після розблокування |
| Музика YouTube з вимкненим екраном | YouTube без Premium зупиняє відео з вимкненим екраном | Відтворення починається одразу після розблокування |
| Одночасно українська + російська + англійська | Модель Vosk розпізнає одну мову | Друга модель (англ./рос.) слухає під час запису команди; Claude виправляє назви («білівер» → «Believer») |
| Слухати, коли мікрофон зайнятий | Під час дзвінка, запису відео, диктофона чи Google Assistant Android віддає мікрофон їм | Джарвіс автоматично продовжує, щойно мікрофон звільниться |
| «Безкоштовне» постійне слухання | Безперервне розпізнавання тримає процесор активним | Модель small (~400 МБ пам'яті) або легша nano; батарея витрачається помітно швидше, ніж без Джарвіса |
| Публікація в Google Play | Політика Google Play не пропускає такі програми без окремих погоджень (спецможливості для керування, SMS, дзвінки) | Застосунок призначений для особистого встановлення з APK |
| Дозвіл камери для ліхтарика | Не потрібен узагалі | Не запитується |
| EncryptedSharedPreferences | Google позначив бібліотеку застарілою | Працює й шифрує ключі через Android Keystore; у коді це враховано |

## 12. Як додати нову команду

Кожна шаблонна команда — це об'єкт, що реалізує інтерфейс `VoiceCommand` (файл `commands/Command.kt`):
`parse()` швидко вирішує, чи команда «своя», і повертає `CommandPlan`, а `run` виконує дію.

**Приклад — команда «Джарвіс, увімкни вайфай. Виконуй»** (вона вже є в коді, ось як її додано):

1. У кінець файлу `app/src/main/java/ua/jarvis/assistant/commands/BuiltInCommands.kt` додано об'єкт:

```kotlin
/**
 * «Увімкни вайфай», «відкрий налаштування вай фай».
 * Це й приклад того, як додати власну команду — див. README, розділ 12.
 */
object WifiCommand : VoiceCommand {
    override fun parse(input: CommandInput, ctx: CommandContext): CommandPlan? {
        // input.tokens — слова команди малими літерами, без апострофів і розділових знаків
        if (!input.tokens.joinToString("").contains("вайфай") && "wifi" !in input.tokens) return null
        return CommandPlan("Wi-Fi") {
            // Android 10+ не дозволяє програмам самим вмикати Wi-Fi — відкриваємо системну панель.
            val o = ctx.launcher.start(Intent(Settings.Panel.ACTION_WIFI), "Wi-Fi")
            outcomeResult(o, "Відкрито панель Wi-Fi", "відкрию панель Wi-Fi")
        }
    }
}
```

   Нагорі файлу — імпорти `android.content.Intent` і `android.provider.Settings`.

2. У `commands/CommandRouter.kt` команду вписано в список `commands`. **Порядок важливий**: виграє перша команда,
   що впізнала текст, тому конкретні команди ставте вище за загальні (`OpenAppCommand` — останній):

```kotlin
val commands: List<VoiceCommand> = listOf(
    YouTubeCommand,
    WifiCommand,      // ← нова команда
    FlashlightCommand,
    ...
)
```

3. Інтент, якого ще немає в `<queries>` у `AndroidManifest.xml`, треба туди додати — інакше Android 11+
   «не побачить» програму, що його обробляє:

```xml
<intent>
    <action android:name="android.settings.panel.action.WIFI" />
</intent>
```

4. Перевірте, що ключове слово є у словнику моделі Vosk (`graph/words.txt` усередині теки моделі) — слова, якого там
   немає, модель ніколи не видасть дослівно. «вайфай» є.
5. Небезпечна дія? Попросіть підтвердження голосом:
   `CommandPlan("Видалити нотатки") { io -> if (!io.confirm("Видалити всі нотатки?")) return@CommandPlan CommandResult(false, "Скасовано"); … }`.
6. Перевірте розбір тестом у `app/src/test/…` і запустіть `./gradlew testDebugUnitTest`.

**Готові помічники:** `UkNumbers.parseTime()` / `parseDurationSeconds()` / `findFirst()` — числа й час словами,
`ctx.apps.find("назва")`, `ctx.contacts.find("ім'я")`, `ctx.device.*` (ліхтарик, гучність, будильник, SMS, карти…),
`ctx.launcher.start(intent, "назва")` — відкриття програм з урахуванням обмежень Android, `io.say("…")` — сказати.

**Нова дія для розумного режиму (Claude):**
1. `smart/AgentPrompt.kt` → допишіть дію й опис у `ACTIONS`; якщо потрібні нові параметри — додайте їх у
   `decisionSchema()` → `params.properties`.
2. `smart/AgentExecutor.kt` → у `execute()` додайте гілку `"назва_дії" -> { … }`, що повертає `Outcome`.

## 14. Приватність, безпека, вартість

* **Звук не покидає телефон.** Розпізнавання — Vosk на пристрої. В інтернет ідуть лише: текст команди розумного
  режиму (до Anthropic), пошуковий запит пісні (до Google/YouTube) і завантаження моделі.
* **Ключі** зберігаються в EncryptedSharedPreferences (ключ шифрування — в Android Keystore); резервне копіювання
  в хмару вимкнене.
* **Вміст екрана** читається службою спеціальних можливостей лише під час виконання команди в розумному режимі.
  Claude проінструктовано вважати текст з екрана даними, а не командами; незворотні дії завжди підтверджуються голосом —
  незалежно від того, що «вирішив» Claude.
* **Вартість Claude API** (оплата за використання): простий крок розумного режиму — орієнтовно 1–2 центи на
  `claude-opus-5-5` і менше 0,1 цента на `claude-haiku-5-5`; багатокрокова дія в іншій програмі (читання екрана
  кілька разів) — кілька центів і більше. Шаблонні команди безкоштовні. Поточні ціни —
  на сторінці тарифів Anthropic.
* **YouTube Data API** — безкоштовно в межах квоти (~100 пошуків на добу).
