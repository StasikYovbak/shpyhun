# Облік годин — як зібрати APK

Додаток для обліку робочих годин: Kotlin + Jetpack Compose, дані в JSON-файлі,
нагадування через AlarmManager. Збірка APK — безкоштовно, прямо на GitHub,
телефон і Android Studio не потрібні.

---

## Варіант А (найшвидший) — файли вже у твоєму репозиторії

Усе залито в гілку `claude/android-worktime-app-21nbql` репозиторію `shpyhun`.
GitHub Actions запускається сам на кожен push, тож APK вже збирається.

1. Відкрий свій репозиторій на GitHub.
2. Угорі натисни вкладку **Actions**.
3. Зліва обери workflow **Build APK**.
4. У списку натисни на найсвіжіший запуск (зелена галочка = зібралось,
   жовте коло = ще збирається, зачекай 3–5 хвилин і онови сторінку).
5. Прокрути сторінку запуску вниз до блоку **Artifacts**.
6. Натисни на **app-debug** — завантажиться `app-debug.zip`.
7. Розпакуй його — усередині `app-debug.apk`. Це і є додаток.

> Червоний хрестик? Зайди в запуск, натисни на крок, що впав, і подивись лог —
> там буде точна причина.

## Варіант Б — створити новий окремий репозиторій

### Крок 1. Створити репозиторій
1. Зайди на https://github.com і натисни **+** у правому верхньому куті →
   **New repository**.
2. **Repository name**: наприклад `worktime`.
3. Постав **Public** (для приватного репозиторію Actions теж працює, але має
   ліміт безкоштовних хвилин).
4. **НЕ** став галочку «Add a README file» — репозиторій має бути порожній.
5. Натисни **Create repository**.

### Крок 2. Залити файли

**Через браузер (без командного рядка):**
1. На сторінці порожнього репозиторію натисни посилання
   **uploading an existing file**.
2. Перетягни у вікно **всі папки й файли проєкту одразу** (`app`, `gradle`,
   `.github`, `gradlew`, `gradlew.bat`, `build.gradle.kts`,
   `settings.gradle.kts`, `gradle.properties`, `.gitignore`).
   Структуру папок GitHub збереже сам.
3. Унизу натисни **Commit changes**.

> Важливо: файл `gradle/wrapper/gradle-wrapper.jar` теж має залитися — без нього
> збірка не піде. Після заливки перевір, що він є в репозиторії.
> Файл `local.properties` заливати НЕ треба (він у `.gitignore`).

**Через командний рядок:**
```bash
git init
git add .
git commit -m "Облік годин"
git branch -M main
git remote add origin https://github.com/ТВІЙ_НІК/worktime.git
git push -u origin main
```

### Крок 3. Забрати APK
1. Вкладка **Actions** → workflow **Build APK** → найсвіжіший запуск.
2. Блок **Artifacts** унизу сторінки → **app-debug** → завантажується zip.
3. Розпакувати → `app-debug.apk`.

Можна також запустити збірку вручну: **Actions** → **Build APK** →
кнопка **Run workflow** справа.

---

## Крок 4. Встановити на телефон

1. Перекинь `app-debug.apk` на телефон (кабель, Telegram «Збережені», Google Drive).
2. Відкрий файл у файловому менеджері й натисни **Встановити**.
3. Android запитає дозвіл встановлювати з невідомих джерел — дай його
   тому додатку, з якого відкриваєш APK (Файли / Chrome / Telegram).
4. Це debug-APK, підписаний тестовим ключем — для власного користування
   цього достатньо. У Google Play такий не завантажити.

## Крок 5. Перший запуск

1. Додаток одразу попросить дозвіл на **повідомлення** — натисни «Дозволити»,
   інакше нагадування не приходитимуть.
2. Зайди в **Налаштування** в самому додатку і перевір рядок
   **«Точні будильники»**. Якщо написано «заборонено» — натисни
   **«Дозволити точні будильники»** і увімкни перемикач у системних налаштуваннях.
   Без цього нагадування можуть спізнюватися на кілька хвилин.
3. Там же за потреби зміни норму годин і час нагадувань.

## Що вміє додаток

**Головна**
- Великі кнопки **Прийшов** / **Пішов** — записують поточний час.
- **Змінити прихід / Змінити вихід** — TimePicker, 24-годинний формат,
  якщо забув натиснути вчасно.
- Статус дня: Робочий / Відпустка / Лікарняний / Святковий.
  У трьох останніх норма за день = 0, і це не рахується недоробітком.
- Перемикач **Обід** — якщо якогось дня обіду не було, вимкни його
  саме в картці того дня.
- Підсумок за сьогодні, за тиждень і за місяць.
- Список останніх 14 днів — тапни по будь-якому, щоб виправити.

**Статистика**
- Фільтри: **Тиждень** (з понеділка), **Місяць** (з 1 числа),
  **Період** (дві дати через DatePicker), **З дати по сьогодні**.
- Підсумок: відпрацьовано, норма, переробіток/недоробіток —
  у форматі «8 год 30 хв» і десятковому «8.5» поруч.
- Зелений = переробіток, червоний = недоробіток.
- Нижче — список усіх днів періоду.

**Налаштування**
- Норма годин окремо на кожен день тижня (за замовчуванням Пн–Пт 8 год,
  Сб 6 год, Нд 0).
- **Обід** — вмикається/вимикається, тривалість за замовчуванням 1 год.
  Віднімається автоматично: з 09:00 до 18:00 буде 8 год, а не 9.
  Від змін, коротших за 6 год, обід не віднімається (це теж налаштовується).

**Нагадування**
- Не приходять у неділю.
- Не приходять, якщо відповідна відмітка за сьогодні вже стоїть.
- Не приходять, якщо день позначено як відпустка/лікарняний/святковий.
- Переживають перезавантаження телефона.

**Особливі випадки**
- Нічна зміна: 22:00 → 06:00 = 8 год (а не мінус 16). Години зараховуються
  дню, коли зміна почалась.
- День лише з приходом позначається «незавершений» і не ламає підрахунок.
- Періоди через межу місяця й року рахуються правильно.
- Відпрацьовано = вихід − прихід − обід. Обід можна вимкнути глобально
  в налаштуваннях або для окремого дня в його картці.

## Де лежать дані

`/data/data/com.stasik.worktime/files/worktime.json` — внутрішня пам'ять
додатка. Видалення додатка стирає дані.

## Технічні деталі

| Параметр | Значення |
|---|---|
| Пакет | `com.stasik.worktime` |
| Kotlin | 2.0.21 |
| Android Gradle Plugin | 8.7.2 |
| Gradle | 8.9 |
| compileSdk / targetSdk | 35 |
| minSdk | 26 (Android 8.0) |
| UI | Jetpack Compose, Material 3 |
| Збереження | JSON через kotlinx.serialization |

Без Room, без Hilt, без Navigation Component — екрани перемикаються
звичайною state-змінною.
